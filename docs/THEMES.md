# 转场语法：随主题变

**不变的规则**：每个转场只做一个发现，一句话说清，≤ 15 秒，一套连续的物理逻辑，那一刻留呼吸；p = 1 交接到墙上挂着的那件原件。
**会变的是语法**：用什么"材料"讲这个发现。艺术史用作品自己的内容（光、雾、笔触）；历史用地图和器物；宗教用建筑、光、文字和声音；中国艺术用卷轴、墨、纸、印。

写方案时在 plan 的 `grammar` 里写明用本文哪一种手段；下面的例子是起点，事实都要交核查 agent 复核后才能上画布。

## 怎么找"那个发现"（通用）
1. 列出两件作品之间**真实存在**的联系：引用与借用、同一母题、同一材料或技法、同一地点、同一个人、一件东西的流转。
2. 或者：下一个单元最核心的手法/观念，作用在上一件作品上（卡拉瓦乔的光选中了人；浪漫主义的雾吞掉了理性的网格）。
3. 用一句话说出来。说不出来，或者要用"同时"、"另外"连接两件事，就不是一个发现。
4. 找依据：学者的论述、原作上看得见的细节、文献。只是"看起来像"的，要在字幕里留余地，或者换一个。
5. 问：这个发现发生在什么"物质"里？选这个主题语法里最贴近的那一种手段来演。

## 艺术史（已完成：艺术的演进）
**语法**：作品自己的内容。光、雾、天气、镜头、颜料、材料。转场就是这幅画最本质的东西。

**用过且用户认可的**
- 巴洛克 · 光选中了人：《创造亚当》里亚当的手翻过来，成了卡拉瓦乔画里基督召唤的手（卡拉瓦乔确实引用了米开朗琪罗）；窗口打开一道光，扫过墙，选中马太。
- 浪漫主义 · 雾吞掉了网格：雾从《荷拉斯兄弟之誓》的三道拱门里渗出来，沿着看不见的三分网格漫开，吞掉理性的画面；剑的汇聚点成了流浪者的后脑勺。
- 当代 · 重复到无限：贾德堆叠单元的漆面熄灯后成了镜子，一盏灯被镜子复制到无限，成了草间的镜屋。

**其他可用手段**
1. 新单元的技法作用在旧画上：印象派的笔触一笔笔重画上一幅画（离线预渲染成视频）。
2. 作品之间的母题接力：同一个姿势、同一道光、同一片风景在两幅画里的位置对上。
3. 镜头一次连续运动（推近、俯下、后拉）把局部变成下一幅画的整体：后印象派"颜色在眼睛里调"——推近看到纯色点，一次长后拉在眼睛里合成《大碗岛》。
4. 材料变化：平面色块在顶光下凸出来成了贾德的物体。

**展项**：荡秋千（拉绳节奏、鞋飞出来能接住）· 拖动窗户改变光落在谁身上 · 离远看点彩在哪一步融合 · 甩漆。

## 历史
**"作品"是什么**：原始地图、器物（钱币、印章、兵器、瓷器）、文献（诏书、条约、账簿、碑刻拓片）、遗址照片。每厅挂一件著名的原件。地图可以是转场的舞台，但交接时要落到挂着的那件原件上。

**地图还是器物？**
- 用地图：发现是空间的——疆域变化大、路线、迁都、贸易与传播、战争的走向。
- 用器物：发现关于一个人、一种制度、一个观念——统一的钱币、一方玉玺、一份诏书。
- 常见组合：器物 → 地图 → 器物。上一厅的器物落到地图上，地图演完这一段，镜头推回下一件器物。

**地图的做法**
- 边界像墨一样流：用两个年份疆域的有符号距离场（SDF）插值，边缘加纸上墨晕的纹理，不做多边形硬变形。年份数字在角落跟着走。
- 地图的样式随时代变：底图用那个时代的制图风格（中国：格网的《禹迹图》式、方志舆图式；欧洲：托勒密式、波特兰海图的罗盘线、墨卡托）。投影也可以在转场里连续变换，本身就是发现（人们看世界的方式变了）。
- 数据：现代海岸线用 Natural Earth（公有领域）；历史疆域用开源历史 GIS 数据（如 CHGIS、historical-basemaps 等，逐个核实许可和精度），离线烘焙成路径或 SDF 纹理放进 rooms/<id>/。不用任何在线瓦片服务（0 外部请求）。
- 措辞：历史疆域都是近似，写"约"，展签注明数据来源；涉及今天仍有争议的边界，按学界通行画法并在文字里留余地。

**转场点子**
1. **钱币的边界就是国家的边界**（秦统一）：六国的刀币、布币、蚁鼻钱在地图上各占一块墨色；一枚半两钱落下，它流通的范围像墨一样漫开，吞掉六块颜色——统一货币就是统一。
2. **一件东西走过的路**：一枚拜占庭金币（北朝至唐的中国墓葬里出土过）从君士坦丁堡出发，沿着路线的那根线把镜头拉过整张地图，落进墓葬，交接到下一件器物。
3. **都城是一盏灯**：地图上一盏灯标出都城，年份往前走，灯从长安移到洛阳、开封、杭州、北京；底图的制图风格在灯下跟着朝代换。
4. **一句条文就是一条经线**（1494 年托德西利亚斯条约）：条约手稿上的一行字，墨线延长出纸面，成了地图上那条分界线，两边的航线随之展开。
5. **地图自己在变**：T-O 地图的圆在大航海之后张开，海岸线连续地重投影成墨卡托的格网；1507 年瓦尔德塞弥勒的地图第一次写上"America"。

**展项点子**
- **驿马传书**：把一封信沿着真实的道路拖过去，沿途的驿站、山地、河流决定速度，时间按史料的日程累加；换成另一个朝代的路网再送一次。
- **季风航海**：拉帆、看风，按月份变化的季风决定船能不能走；错过季风就要等半年。
- **拓印**：在一块碑上按住拖动拓包，墨一层层上去，字从白里显出来；用力大小决定浓淡。

## 宗教的发展
**语法**：建筑与光（石窟、神庙、窣堵坡、教堂、清真寺）、文字与经典、图像志（手印、光环、姿态）、仪式的声音。

**分寸**（每厅都要遵守）
- 尊重、平衡、有出处。信仰的说法写"信徒相信 / 传统说法"，历史与学术写"学者认为"；有争议并列两说，本展不裁决。
- 不暗示一种宗教"变成"另一种，除非传播或借用有文献与考古依据（例如犍陀罗佛像的希腊化衣纹）。只是相似的，只说相似，并写明各自的含义不同。
- 不扭曲、不拼贴、不戏仿神圣形象；展项不让观众涂改神像或经文。
- 伊斯兰传统通常避免描绘先知的形象：展示中遵从，用建筑、书法、几何纹样来讲。
- 仪式声音（诵经、钟、宣礼）只用在环境和那一刻，不做花哨音效；录音许可与语境都要核实。

**转场点子**
1. **光从穹顶的洞口到悬浮的穹顶**：万神殿圆洞投下的光斑在穹顶内壁上移动；光斑扩成一圈窗，穹顶像浮起来，成了圣索菲亚大教堂（普罗科匹厄斯写它像从天上悬挂下来）。
2. **衣纹走过了兴都库什**：希腊化雕像的衣褶线条保持不动，镜头移开，同样的褶皱落在犍陀罗佛像的袈裟上。发现是衣纹，不是面孔，不做变形。
3. **经文可以重复了**：一叶贝叶经的横行文字，墨色移到木版上，印出敦煌的《金刚经》（868 年，现存最早有明确纪年的印本，卷末写着为父母敬造普施）。
4. **一个圆长出整面墙**：一个圆被圆规等分，按尺规作图的规则长出星形和交错的线，一直铺满墙，落定成一座清真寺的瓷砖面——不画人像，几何与书法承担了装饰。
5. **钟声**：一声钟响，余音衰减的同时光线暗下去，下一个空间在同一声余音里亮起（佛寺的梵钟 → 教堂的钟）。声音是这一段的物理逻辑。

**展项点子**
- **太阳的日子**：拖动日期和时刻，看光怎样走进神庙：阿布辛贝神庙每年约 2 月、10 月各一次照进内殿雕像；万神殿的光斑随季节在穹顶上移动。
- **尺规作图**：用圆规和直尺作图，按规则一步步长出伊斯兰几何纹样；做错一步，图案就接不上。
- **搭一座拱**：一块块放楔形石，抽掉拱架；拱顶石放好前拱会塌。之后再试穹顶和帆拱。

## 中国艺术
**语法**：手卷是横向的时间，挂轴是竖向的空间；墨在宣纸上洇开；留白；笔的节奏；印章和题跋是一层层叠上去的历史；装裱的绫绢；竖排的宋体、楷体；古琴、琵琶；石青、石绿、朱砂这样的矿物颜料。转场要有中国传统的质感，不借用西方的光影戏剧。

**做法**
- 手卷从右往左展开，一次看一段（约一臂之宽）；镜头也从右往左走。
- 墨晕：离线模拟墨在纸纤维里扩散，预渲染成视频或序列帧；纸纹用真实宣纸扫描（自己拍或公有领域），不用程序噪声糊弄。
- 字：竖排（`writing-mode: vertical-rl`），宋体或楷体（思源宋体、霞鹜文楷等 OFL 字体，自托管并按用字子集化）。标题可用书法原迹。
- 颜色：墨分五色；绢的暖黄；印泥朱红；青绿山水的石青、石绿。墙色可取装裱的绫绢色。
- 交接的画框：`frame` 用装裱样式（天头、地头、隔水），手卷可以横挂在长案上。

**转场点子**
1. **墨在纸上洇开**：上一件作品最深的一块墨在湿纸上洇开，洇开的边缘成了下一幅的山形（例如范宽的雨点皴 → 米芾、米友仁的"米点"云山：墨点就是湿润的山）。
2. **手卷就是时间**：《清明上河图》从右往左展开，郊野 → 汴河 → 城门，镜头一段段走过；画卷本身就是一天、一座城。上一厅的最后一段就是这一卷的起首。
3. **盖上一方印**：那一刻是一方印落下。同一件法书上，历代收藏者的印一方接一方落下，每方印伴着它的年代（例如《快雪时晴帖》上乾隆的大量题跋和印章）；最后一方印的朱红留下来，是下一厅的开始。
4. **题跋一层层长出来**：画心之后，一段段题跋按时间在拖尾上写出来（按笔顺，预渲染），画的历史写在它自己身上。
5. **留白即云水**：颜色退去只剩墨，空白处开始流动，成了雾和水，镜头落到马远"一角"的构图上——大片空白就是画的主体。

另可：石青石绿的颗粒一层层落在绢上成了《千里江山图》（1113 年，王希孟）的青山。

**展项点子**
- **展开一卷**：两手各拖一头，卷起右边、展开左边，一次只看一段；卷得快画会"跑"，停下来细部才清楚。
- **盖印**：选印章、蘸印泥、按下，按的轻重和印泥多少决定印文虚实；看历代收藏印怎样挤满一张纸。
- **古琴泛音**：在琴面的十三个徽位上轻点琴弦，得到泛音（徽位在弦长的简单分数处）；按实音和泛音对比听。
- 也可：毛笔的轻重快慢决定干湿和飞白，墨在宣纸上洇开。

**声音与音乐**：古琴、琵琶、箫。公有领域或自由许可的录音少，要早找；作品与录音的许可都要核实，找不到宁可用安静的环境声，不用廉价合成的"中国风"。

## 新主题怎么定语法
1. 这个领域里意义由什么"物质"承载？（艺术：颜料、光；历史：空间和时间；宗教：空间、光、文字、声音；中国艺术：墨、纸、卷、印）
2. 在那个物质里，什么变化是连续、真实、可以一句话说出的？
3. 这个领域的"原件"是什么，交接时挂哪一件？
4. 有哪些禁区（敏感、尊重、事实争议）？写进 plan 的 `_rules`。
5. 先做一个样板厅给用户看，认可后再铺开整批。
